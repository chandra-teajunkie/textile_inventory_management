# Textile Inventory Management Software

This repo contains both the frontend and backend components for the Textile Inventory Management Software.

## Repository Structure

*   `frontend/`: Contains the Node.js frontend application.
*   `backend/`: Contains the Python FastAPI backend application (this directory).
