# 🧵 Textile Inventory Management App

A modern React-based application to manage textile orders and size charts. Supports CSV/Excel uploads, order creation, and task tracking with a clean UI.

---

## 🚀 Features

- 📋 Create and submit textile orders
- 📁 Upload size charts (Excel/CSV)
- 🧭 Tabbed interface for order creation and task management
- 🔨 Add tasks for each order (with status selection)
- ✅ Backend integration (POST/GET via API)
- 🎨 Built with TailwindCSS and React

---

## 📦 Tech Stack

- [React](https://reactjs.org/)
- [TailwindCSS](https://tailwindcss.com/)
- [react-select](https://react-select.com/)
- [react-datepicker](https://reactdatepicker.com/)
- [xlsx](https://www.npmjs.com/package/xlsx)

## Frontend Developer Setup

This section outlines the steps to set up the backend development environment.

### Prerequisites

*   Node *latest*
*   npm *latest*
*   Git

### Installation

1.  **Clone the repository:**

    ```bash
    git clone <your_repository_url>
    ```

2.  **Navigate to the `frontend` directory:**

    ```bash
    cd frontend
    ```


3.  **Install dependencies**

    ```bash
    npm install
    ```

4. **Ensure the PORT and Enpoints from `.env` file**

5.  **Start the App**

    ```bash
    npm start
    ```

6. App should run at: **http://localhost:3001**
